# De Little Goa

**Live site:** [https://de-little-goa.vercel.app](https://de-little-goa.vercel.app)

Website for De Little Goa, a Goan restaurant, built with React and Vite.

## Features

- Hero, about, menu, and gallery sections
- Customer reviews
- Location section
- WhatsApp contact button
- Fully responsive layout

## Tech stack

- [React](https://react.dev/) 19
- [Vite](https://vite.dev/)

## Project structure

```
src/
  components/   Page sections (Header, Hero, AboutUs, Menu, FeaturedDishes, Gallery, Reviews, Location, Footer, WhatsAppButton)
  App.jsx        Main app entry
  main.jsx        Vite entry point
public/assets/    Site images
```

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview   # preview the production build locally
```

## Linting

```bash
npm run lint
```
